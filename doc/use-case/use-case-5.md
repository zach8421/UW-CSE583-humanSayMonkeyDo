### Use Case: Add a New Decoding Method

**Goal**  
Allow Tom to add or modify decoding algorithms within the tool.

**User**  
Tom

**Inputs**  
- Existing neural dataset (human or monkey)
- Tom’s new or updated decoding function

**Outputs**  
- A new decoding option available in the analysis interface or script API

**Steps**  
1. Tom opens the decoding module in the codebase.
2. He adds or updates a decoding function following the existing function template.
3. The tool automatically recognizes the new method and lists it as a selectable option.
4. Tom tests the new method on sample monkey and human datasets.
5. The tool displays results for Tom to verify and compare with existing methods.
