### Use Case: Visualize and Quality Check New Data

**Goal**  
Let Mabel quickly inspect new recordings to confirm data quality before deeper analysis.

**User**  
Mabel

**Inputs**  
- Newly collected neural data

**Outputs**  
- Raster plots, firing rate traces, or other quick visual checks

**Steps**  
1. Mabel opens the new dataset in the tool.  
2. The tool displays basic visualizations of neural activity.  
3. Mabel checks for expected patterns (e.g., signal stability, trial structure).  
4. If needed, she adjusts preprocessing settings and rechecks.  
5. Mabel confirms the data is ready for downstream analysis.
