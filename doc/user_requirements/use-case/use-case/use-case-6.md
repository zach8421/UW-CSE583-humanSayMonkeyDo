### Use Case: Inspect Code Execution and Debug Results

**Goal**  
Allow Tom to verify that each step of the analysis pipeline is working correctly.

**User**  
Tom

**Inputs**  
- Any dataset currently being analyzed

**Outputs**  
- Step-by-step logs showing each processing stage

**Steps**  
1. Tom switches the tool into “Debug / Inspect Mode.”  
2. The tool shows intermediate results for each stage of the pipeline.  
3. Tom checks whether the processing steps behave as expected.  
4. If something looks incorrect, Tom adjusts the code or settings.  
5. Tom re-runs the analysis to confirm the fix.
